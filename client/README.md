# CodeLens Frontend

This directory contains the React/Vite single-page application for CodeLens.

## Responsibilities
The client is responsible for rendering the intelligence generated by the backend. It handles ZIP uploads, visualizes dependency graphs using React Flow, renders Mermaid architecture diagrams, and embeds the Monaco Editor for source exploration.

## Technology Stack
- **React 18**
- **Vite**
- **Tailwind CSS**
- **React Router**
- **React Flow**
- **Mermaid.js**
- **Monaco Editor**
- **Axios**

## Running Locally

```bash
cd client
npm install
npm run dev
```

The frontend will run on `http://localhost:5173`. Ensure the backend is running on `http://localhost:3001`.

## Routing

The entry point for an uploaded repository is `/explore/:repoId`. This routes to `RepositoryIntelligencePage.jsx`. From there, developers can navigate to specialized views like `/explore/:repoId/source` (Explorer) or `/explore/:repoId/graph` (Dependencies).

All major pages feature a consistent header and a "Back to Intelligence" breadcrumb to maintain navigational context.
