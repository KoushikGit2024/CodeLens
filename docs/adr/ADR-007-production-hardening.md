# ADR-007: Production Hardening, Quality & Intelligence Validation

## Context
As CodeLens scaled to support multiple languages and complex analytical models (Architecture, CI/CD, Dependency Graph), several potential security and reliability gaps surfaced. 

Specifically:
- Source references (file paths and line numbers) generated by the AI model were passed verbatim to the frontend, leading to potential 404s when hallucinated.
- The AI context building step lacked robust fallback mechanisms if the AI provider failed or returned non-compliant JSON, risking system panics.
- Zip extraction, though protected against relative path traversals, needed extra hardening against explicitly absolute path payloads.
- The `ArchitectureModel` aggregated structural components but failed to directly surface anomaly indicators (cycles, unresolved imports), making it harder for consumers (and the AI) to detect systemic rot.

## Decision
We decided to enforce a strict boundary validation pattern across the entire system.

1. **Deterministic Bounds Checking**: `FileAnalysis` now computes and stores `lineCount` during the AST parsing phase. This explicitly bounds AI-generated references. 
2. **AI Result Validation**: File references provided by AI (e.g. in Question/Ask endpoints) are rigorously checked. Paths must exist in `record.analysis.files`, and lines must fall between `1` and `file.lineCount`.
3. **Extraction Hardening**: Absolute paths are unconditionally dropped in `zipExtractor.js` before `path.resolve` handles them, neutralizing exotic zip payloads.
4. **Architecture Anomalies**: `cycles` and `unresolvedDependencies` metrics are natively injected into the Architecture Model output from the underlying graph layer.

## Consequences
- **Positive**: Eradicates AI hallucinations from reaching the UI. If the AI hallucinates a non-existent file, it's silently dropped. If it hallucinates out-of-bounds lines, the file link is preserved but line highlights are disabled.
- **Positive**: AI provider downtimes consistently downgrade into deterministic modes without crashing the Node.js process.
- **Positive**: Enhanced security posture against malicious Zip bombs.
- **Negative**: Very slight performance overhead during reference extraction and AST parsing (`split('\n')`), but negligible within the 512KB file limits.
