# Frontend Overview

The CodeLens frontend is a single-page application (SPA) built with React and Vite. It is designed to visualize the complex deterministic data generated by the backend and facilitate interaction with the AI repository assistant.

## Tech Stack
- **React 18**
- **Vite** (Build tool)
- **Tailwind CSS** (Styling)
- **React Router** (Navigation)
- **React Flow** (Dependency graph visualization)
- **Mermaid.js** (Architecture visualization)
- **Monaco Editor** (Source code viewing)
- **Axios** (API client)

## Core Responsibilities

1. **Upload & Onboarding**: Guides users to upload `.zip` repositories.
2. **Unified Dashboard (`RepositoryIntelligencePage.jsx`)**: Displays high-level repository facts, hotspots, and health.
3. **Deep Visualizations**: Renders large dependency networks (`DependencyGraphPage.jsx`) and architectural models (`ArchitecturePage.jsx`).
4. **Code Viewing (`ExplorerPage.jsx`)**: Embeds Monaco editor with a file tree to explore source code.
5. **AI Interaction**: A persistent side-panel provides the "Repository Assistant" interface for Q&A, and components render the structured AI interpretations for documentation and refactoring.
